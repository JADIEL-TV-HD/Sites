# JADIEL IA Web

IDE educacional para hospedagem compartilhada como InfinityFree.

## Hospedagem
- Front-end: HTML, CSS e JavaScript puro.
- Sem Node.js, build obrigatório ou servidor dedicado.
- Pode ser publicado diretamente no `htdocs`.
- PHP pode ser adicionado posteriormente para salvar projetos, contas ou persistência no servidor.

## Recursos atuais
- Editor HTML/CSS/JavaScript
- Preview em tempo real via iframe sandbox
- Execução com Ctrl+Enter
- Partículas animadas
- Interface responsiva inspirada em IDEs
- Aulas e arquivos do projeto
- Importação de código HTML

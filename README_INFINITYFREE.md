# JADIEL AI — InfinityFree

Estrutura:
- index.php
- api/chat.php
- config.php
- config.example.php
- .htaccess

## Configuração

1. Envie os arquivos para a pasta pública do InfinityFree.
2. No servidor, abra config.php.
3. Substitua COLOQUE_SUA_CHAVE_AQUI pela sua chave Gemini.
4. Não coloque a chave real no index.php, JavaScript ou GitHub.
5. O index.php chama api/chat.php; a API chama o Gemini no servidor.

A chave real não deve ser publicada no repositório.
